# YouTube Video Download Skill

Download YouTube videos locally for offline viewing. No API keys, no subscriptions, no logins required.

## Primary Tool: yt-download script

A wrapper script at `~/.local/bin/yt-download` that handles format selection, merging, and output.

```bash
yt-download "<youtube_url>" [quality] [lang]
```

**Quality options** (default: `best`):
- `best` — Best video + best audio, merged to MP4
- `1080` — Up to 1080p
- `720` — Up to 720p
- `480` — Up to 480p
- `360` — Up to 360p
- `audio` — Audio only, extracted to MP3
- `transcript` — Auto-generated captions only, saved as `.srt` (no video/audio)

**Output organization**: Every download is saved into its own folder named after the video title:

```
~/Videos/
└── <video title>/
    ├── <video title>.mp4      (video download)
    ├── <video title>.mp3      (audio download)
    └── <video title>.en.srt   (transcript download)
```

Video, MP3, and transcript downloads of the *same* video share one folder, so no manual organizing is needed after the fact.

**Examples**:
```bash
yt-download "https://www.youtube.com/watch?v=u5h2OCcKYkc"
yt-download "https://www.youtube.com/watch?v=u5h2OCcKYkc" 720
yt-download "https://www.youtube.com/watch?v=u5h2OCcKYkc" audio
yt-download "https://www.youtube.com/watch?v=u5h2OCcKYkc" transcript
yt-download "https://www.youtube.com/watch?v=u5h2OCcKYkc" transcript pt
yt-download --list
```

## Download log & dedup

Every download is logged to a local SQLite database at `~/Videos/.downloads.db` (uses Python's `sqlite3` module — no `sqlite3` CLI needed). Each row records the video id, URL, title, file type (`mp4` / `mp3` / `srt`), quality, language, file path, size, and timestamp.

- **Dedup**: before downloading, the script checks whether the same video + file type is already logged and skips it — transcripts are additionally keyed by language, so `en` and `pt` are tracked separately. This avoids needless API calls and duplicate files.
- **View the log**: `yt-download --list`
- **Force re-download** of an already-logged item:
  ```bash
  YT_FORCE=1 yt-download "<youtube_url>" best
  ```
- **Query directly**: open the DB with `python3 -m sqlite3 ~/Videos/.downloads.db` (interactive) and run SQL, e.g. `SELECT * FROM downloads WHERE file_type='mp3';`

## Transcripts (auto-captions)

The `transcript` quality downloads only the captions — no video or audio. By default it grabs English auto-generated captions and converts them to `.srt` (SubRip). Pass a language code as the third argument for other languages:

```bash
yt-download "<youtube_url>" transcript        # English auto-captions
yt-download "<youtube_url>" transcript pt     # Portuguese auto-captions
```

- **Auto-captions** (`transcript`) — generated by YouTube's speech recognition; available on most videos. Best for getting a text transcript of a talk/podcast.
- **Manually-uploaded subtitles** (rare) — if a video has no auto-captions but has human subtitles, fall back to raw yt-dlp:

```bash
yt-dlp --skip-download --write-subs --sub-langs "en" --convert-subs srt \
  -o "~/Videos/%(title)s/%(title)s" "<youtube_url>"
```

- **List available caption languages** for a video (useful to see what's available):

```bash
yt-dlp --list-subs "<youtube_url>"
```

Output file: `~/Videos/<title>/<title>.<lang>.srt` (e.g. `... .en.srt`).

## Fallback: Raw yt-dlp

If the script fails, use yt-dlp directly:

```bash
# Best quality (auto-merge video + audio to MP4)
yt-dlp -f "bestvideo+bestaudio/best" --merge-output-format mp4 \
  -o "~/Videos/%(title)s/%(title)s.%(ext)s" "<youtube_url>"

# Audio only as MP3
yt-dlp -f bestaudio -x --audio-format mp3 \
  -o "~/Videos/%(title)s/%(title)s.%(ext)s" "<youtube_url>"

# List available formats (useful for debugging)
yt-dlp --list-formats "<youtube_url>"
```

## Troubleshooting

### JS runtime warning
```
WARNING: [youtube] No supported JavaScript runtime could be found
```
YouTube deprecates extraction without a JS runtime, but the android VR API fallback still works. If formats are missing, install deno:
```bash
# Install deno (one-time)
curl -fsSL https://deno.land/install.sh | sh
# Then use:
yt-dlp --js-runtimes deno -f "bestvideo+bestaudio/best" --merge-output-format mp4 \
  -o "~/Videos/%(title)s/%(title)s.%(ext)s" "<url>"
```

### yt-dlp is outdated
YouTube changes frequently. If downloads fail, update:
```bash
yt-dlp -U
```
Or reinstall:
```bash
pip3 install --upgrade yt-dlp
```

### 403 / "Video unavailable"
The video may be age-restricted, region-blocked, or private. Try adding cookies:
```bash
yt-dlp --cookies-from-browser firefox -f "bestvideo+bestaudio/best" \
  --merge-output-format mp4 -o "~/Videos/%(title)s/%(title)s.%(ext)s" "<url>"
```

### Rate limiting / throttling
yt-dlp automatically handles YouTube's throttling. If downloads are slow, add:
```bash
yt-dlp --throttled-rate 100K ...
```

## Requirements

- **yt-dlp**: Already installed at `~/.local/bin/yt-dlp`. Keep updated with `yt-dlp -U`.
- **ffmpeg**: Already installed at `/usr/bin/ffmpeg`. Required for merging video+audio streams.
- No API keys, no Google account, no YouTube subscription needed.

## Maintenance

Run periodically (monthly or when downloads fail):
```bash
yt-dlp -U
```
