## Quick facts

- **Repo root**: `~/.pi` (`pi-workspace`)
- **Main agent**: `~/.pi/agent/cos-orchestrator-agent` (`PI_CODING_AGENT_DIR`). Launcher `~/.local/bin/pi` sources `~/.pi/agent/.env`, pins Node v24.21.0, starts there.
- **Providers**: deepseek (default), openai, google. Default model `deepseek-flash`, thinking `high`. Enabled: `deepseek-flash`, `deepseek-v4-pro`, `gpt-6.1-sol`, `gemini-3.8-flash`, `gemini-3.7-flash`.

- **Package on COS**: `npm:@llblab/pi-telegram` (Telegram surfaces).

COS settings live in `agent/cos-orchestrator-agent/settings.json`, not in a top-level `agent/settings.json`.

## What COS loads

Pi **auto-discovers** `extensions/*.ts` and `extensions/*/index.ts`. Default is on. The `+` list in `settings.json` is intent, not an off switch. `git-commit.ts` is unlisted and still provides `/commit`. Disable with `-path`, or a non-`.ts` name (`pi-prompt-capture.ts.disabled`).

Listed (and discovered): mode-switch, cron, auto-sync, chat (`/ask` `/usage`), archive, calendar-node, reminder-node, reminder-commands, jev-feedback, input-contains-*, less-than-input-words, input-phrase, prompt-build, secret-scrubber. Also `/commit`.

Project-local (when cwd is `~/.pi`): `.pi/extensions/pi-event-tracer`, `.pi/extensions/session-memory`.

Cron engine is `cron/` at repo root; only COS wires `extensions/cron.ts`.

## Routing (COS only)

A user message can be answered without a model turn:

1. **mode-switch** — `pi-config get/use promptBuild` (off unless `modeSwitch.enabled`).
2. **JEV** — `jev-classifier/` (submodule; `classify.py`). Key: `jev-classifier/.env` (`TYPESAFE_API_KEY`).
3. **calendar / reminder nodes** — `decision-nodes/calendar/` and `decision-nodes/reminder/` (Python). Shared `reminders.jsonl`. Fail-open. Only COS must load these hooks (keep does not, so it cannot double-write).

JEV details: `docs/pi-state-of-jev.md`.
