# Paths /archive must never move.
#
# Read by src/protected-paths.ts before the archive script runs. One pattern per line:
#   - relative patterns are relative to $HOME, `~` is expanded
#   - `*` matches inside one path segment, `**` matches across segments
#   - moving a DIRECTORY that contains a protected path is refused too
# `/archive --undo` and `/archive --list` are never blocked, and `--dry-run` shows what
# would happen without moving anything.
#
# Rationale and the full inventory: agent/docs/runbooks/what-must-remain.md
# Add a line here the first time you find yourself protecting something new.
